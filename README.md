# KKT 북마크 (Clean & Smart Bookmark)

> **광고 없는 쾌적함, 강력한 다단계 계층 폴더(트리 구조)와 다중 태그, 브라우저 지정 실행을 지원하는 북마크 앱**

기존 상용 북마크 앱들의 과도한 광고와 부실한 폴더/태그 분류 기능에서 벗어나, 순수 오프라인 로컬 저장과 깊이 있는 링크 관리를 위해 제작된 모던 북마크 앱입니다.

---

## ✨ 핵심 기능

### 1. 🗂️ 다단계 계층 폴더 (트리 구조)
- **무제한 깊이의 하위 폴더 생성**: 상위 부모 폴더를 자유롭게 지정하여 `홈 > 개발 > 안드로이드 > UI`와 같은 트리 구조를 구축할 수 있습니다.
- **인터랙티브 브레드크럼(Breadcrumb)**: 화면 상단 경로 바를 터치하여 원하는 상위 폴더나 홈으로 즉각 이동합니다.
- **폴더 트리 관리 화면**: 전체 폴더 구조를 들여쓰기 트리 형태로 한눈에 조망하고 수정/삭제/이동할 수 있습니다.
- **폴더별 테마 색상**: 폴더마다 고유 색상을 지정하여 시각적 구분이 용이합니다.

### 2. 🏷️ 유연한 다중 태그 (Multi-Tag)
- 하나의 북마크에 여러 개의 태그(`#개발`, `#레퍼런스`, `#꿀팁`)를 자유롭게 추가할 수 있습니다.
- 상단 가로 스크롤 태그 필터 바를 통해 원하는 태그의 북마크만 즉시 모아볼 수 있습니다.

### 3. 🌐 실행 브라우저 자유 지정 (신규 추가!)
- 북마크를 열람할 때 원하는 브라우저 앱을 직접 선택할 수 있습니다:
  - **시스템 기본 브라우저**, **구글 크롬(Chrome)**, **삼성 인터넷**, **네이버 앱**, **네이버 웨일**, **MS 엣지**, **파이어폭스**
- 북마크별로 전용 브라우저를 지정하거나, 북마크 카드의 더보기 메뉴에서 그때그때 원하는 브라우저로 골라서 실행할 수 있습니다.
- 모바일(안드로이드) 환경에서는 Intent Scheme을 통해 해당 브라우저 앱을 다이렉트로 실행합니다.

### 4. ⚡ 카카오톡 & 브라우저 '공유하기' 원클릭 저장
- 다른 앱(카카오톡, 크롬, 삼성 인터넷 등)에서 링크 공유 시 바텀시트가 팝업되어 1초 만에 폴더/태그를 지정하여 저장할 수 있습니다.
- OpenGraph 메타데이터(제목, 썸네일 이미지, 설명, 파비콘)를 백그라운드에서 자동 수집합니다.

### 5. 🚫 100% 광고 없는 오프라인 로컬 데이터베이스
- 불필요한 광고 SDK나 외부 추적 트래커가 전혀 없습니다.
- 회원가입이나 로그인 없이 기기 내부 로컬 저장소에 안전하게 보관되어 개인정보가 완벽히 보호됩니다.

### 6. 🔍 실시간 통합 검색 & 스마트 필터
- 제목, 설명, 사용자 메모, URL, 태그 이름까지 아우르는 실시간 검색을 지원합니다.
- **전체 / ★ 즐겨찾기 / ✉ 읽지 않은 링크** 탭을 통해 읽을거리를 효율적으로 정리할 수 있습니다.

### 7. 💾 완벽한 JSON 백업 및 복원
- 기기 변경이나 데이터 보관을 위해 전체 폴더 계층 구조와 태그, 북마크 데이터를 단일 JSON 파일로 언제든지 내보내고(Export) 복원(Import)할 수 있습니다.

## 🚀 실행 방법

### 방법 1. 인텔리제이(IntelliJ) 또는 터미널에서 즉시 실행 (추천)
무거운 Android Studio 설치 없이, Node.js 환경에서 1초 만에 실행할 수 있습니다:
```bash
npm run dev
```
- **PC 브라우저**: `http://localhost:3002` (실제 스마트폰 목업 프레임 지원)
- **스마트폰(같은 Wi-Fi)**: 브라우저로 `http://[PC_IP]:3002` 접속 후 **"홈 화면에 추가(앱 설치)"**를 누르면 스마트폰 앱 아이콘으로 설치되어 주소창 없이 네이티브 앱처럼 동작합니다.

### 방법 2. Android Studio 네이티브 빌드
- `Android Studio`에서 이 폴더를 열어 Gradle 동기화 후 Run 실행 (Kotlin + Jetpack Compose + Room DB 소스 포함).
